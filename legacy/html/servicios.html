El mismo se trata de un piso de goma encastrable de un grosor y una densidad especial apto para la prctica de Karate-Do y de distintas disciplinas deportivas.
Este piso de goma rene las condiciones de seguridad impuestas por el C.O.I. (Comit Olmpico Internacional), medida indispensable para este y otros deportes, por lo que se torna el objetivo ms importante a cubrir, adems su alta resistencia lo hace ideal para competencias, Gimnasia Olmpica, aerbica, etc. Tambin est preparado para salas infantiles tales como peloteros, jardines de infantes, guarderas, colegios y clubes resguardando la integridad fisica de los nios, previniendo los golpes.

Sus caractersticas especficas es que no retienen la humedad, es trmico por lo que acta como aislante entre el piso y el pi del practicante, antideslizante, es reversible, fcilmente desmontable, apilable y trasnportable, se limpia fcilmente reuniendo condiciones extremadamente higinicas.

El piso de goma es una medida de seguridad para el practicante por lo tanto debemos pensar seriamente en la incorporacin de este y en adecuarnos a las exigencias internacionales tanto de seguridad como de competicin.
